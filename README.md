# CLI Contact Manager
## Description
CLI Contact Manager is a simple yet powerful Dart application for managing your contacts directly from the command line. It allows users to add, display, and save contacts efficiently and intuitively.
## Features
* Add new contacts with detailed information
* Display the complete list of saved contacts
* update existing contact
* delette existing contact
## Prerequisites
* Dart SDK (version 2.12.0 or higher)

## Installation
1. Clone this repository:
   
      git clone https://github.com/sackoba11/contact.git

2. Navigate to the project directory:

   cd contact

3. Run the program:

  dart run main.dart

## Usage
After launching the program, you will be presented with a menu offering the following options:

Gestion des contacts:
1. Ajouter un contact
2. Afficher tous les contacts
3. Modifier un contact
4. Supprimer un contact
5. Quitter
Choisissez une option (1-5):

Choose the corresponding option by entering the appropriate number.
